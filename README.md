# 🎲 Tenzies

A dice game built with React. Roll the dice, freeze the ones you want to keep, and get all ten showing the same number to win. Winning triggers a fireworks animation.

## Run it

```bash
npm install
npm run dev
```

## Built with

* [React](https://react.dev/) (hooks: `useState`, `useEffect`)
* [nanoid](https://github.com/ai/nanoid) for unique dice ids
* [canvas-confetti](https://github.com/catdad/canvas-confetti) for the win animation
* Plain CSS for all styling
